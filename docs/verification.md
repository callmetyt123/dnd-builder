## 与原讨论的实现差距

- 尚无通用 `RuleEffect`、Condition/ValueExpr 或 Choice Graph；`deriveCharacter` 直接引用固定战士、勇士、矮人、士兵数据。架构文档中的 `collectEffects` 流程尚未落地。
- 背景属性 UI 仅提供 +2/+1，校验器虽然接受 +1/+1/+1，但 UI 尚不能选择。
- 速查卡只展示四项关键能力。战术思维、矮人石中精魂/抗性/黑暗视觉、背景起源专长及恢复说明没有完整展示，也没有资源勾选框。
- 速查卡精通列未检查 `unlocked`；当前可生成路径强制选择全部三种已录入武器，所以正常黄金路径未触发错误展示，属于扩展前要处理的问题。
- 完整人物卡与 PDF/PNG 导出明确仍是下一阶段；玩法偏好目前不会改变固定构筑。
