# v0.16 本地验证

日期：2026-09-29。范围：车卡产物拆成三张卡、子职可见性与选中状态修正。

## 本版内容

- 车卡结果拆分为新人上手卡（1 页）、常规人物卡（固定 2 页）、资料速查卡（描述全文）。
- 职业页新增子职状态条与四个缩略选择，选定职业后引导到子职说明；其余步骤保留子职位置提示。
- 玩法页强调「最多选择两个」；常规人物卡列出手上实际拥有的法术名。
- 修正职业配置页选项只设 `aria-pressed` 而无选中样式的问题。
- 开发服务器跳过隐藏目录，避免编辑器临时目录令 Vite 以 EBUSY 退出。

## 自动验证

- `npm run test:rules`：70,016 项检查通过（v0.15 为 68,052）。
- `npm run build`：TypeScript 与 Vite 构建通过，395 个模块。
- 新增断言：9 条基础路线的常规人物卡恰好两页、含当前 HP／临时 HP／资源勾选框／起始装备、且不含 `spell-card` 与 `sheet-features`；资料速查卡保留可记录字段；伙伴数据只进入速查卡；新六职业每个起源组合在拥有法术时必须出现法术名录、至少列出第一道法术名，且不含该法术正文；法师与奥法骑士的法术名录区分戏法与已准备，法师另列法术书中未准备。

## 卡片规模

以脚本对十二职业的默认构筑（含各自入门子职）渲染真实组件统计：

| 卡 | 页数 |
| --- | --- |
| 新人上手卡 | 1 页（全部职业） |
| 常规人物卡 | 2 页（全部职业） |
| 资料速查卡 | 3–10 页；战士 3、游荡者 4、魔契师／游侠／野蛮人／武僧 6、法师 7、吟游诗人／圣武士 8、牧师／术士 9、德鲁伊 10 |

拆分前「完整人物卡」为 4–10 页（法师 8、德鲁伊 10、术士 9）。速查卡页数高于旧完整卡，因为职业能力全文、起源附页与生物数据集中到同一张卡，常规卡不再承担描述。

## 实现过程中被断言拦住的回归

- 战士常规卡缺少「护甲与武器训练」一行，由 `expansionSelftest.ts` 的骑士装备断言发现。
- 奥法骑士法术卡未接入速查卡，由同一组断言发现。
两处均在同一轮修复，未进入提交历史之外的状态。

## 用户反馈的缺陷

- 职业配置页已选技能没有高亮：法师、德鲁伊、游侠、游荡者、魔契师与奥法骑士联结武器只设置 `aria-pressed`，而样式只挂在 `.selected` 上。改为 `.choice-pills button[aria-pressed="true"]` 与 `.weapon-row[aria-pressed="true"]` 后，高亮跟随可访问性状态。
- 常规人物卡缺少法术清单：新增 `spellGroups()`，按职业列出戏法、已准备、法术书未准备与祈唤随意施法，只输出名称。
