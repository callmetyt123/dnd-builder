# v0.7 · 背景独立选择

## 交付

- 士兵、贤者、隐士、流浪者可与五个现有职业自由组合；共 20 种组合。
- 推荐置前并解释理由，自定义专长法术默认折叠。切换背景保留基础属性与职业选择，背景加值改为当前组合的合法推荐值；恢复推荐属性也遵循当前背景。
- 重复技能作为建议，支持显式调整；失去熟练的学者／游侠专精阻止生成并提供修复入口。
- 背景技能、工具、装备、专长和每日资源独立于职业派生；贤者法术使用独立施法属性与附页，不占职业准备名额。
- 修复旧固定组合文案：医疗师重掷、幸运、凶蛮打手、工具熟练、医疗包及长棍法器来源不再泄漏到其他背景。
- 保持 schemaVersion 1 与存储键，迁移旧赌具和魔法学徒字段；包括暂存的职业选择、姓名与已记录 HP。畸形草稿仍保留供恢复。

## 验证

- `npm run test:rules`：651 项检查通过，包含 20 种组合的规则计算、快速／完整人物卡渲染、来源隔离、推荐修复、非法来源拒绝、旧草稿迁移和原五职业回归。
- 生产构建通过。
- 桌面：战士 → 贤者 → 自定义专长施法属性 → 恢复推荐属性 → Review → 快速／完整卡。验证缺少戏法阻止继续，合法非推荐组合不被阻止；专长附页正确、无旧凶蛮打手或错误法器标签。
- 手机 390×844：法师 → 流浪者，出现重复技能和失效专精提示；一键调整后提示消失。纸牌套组在刷新后保留。法术书与职业准备数保持，生成卡中有幸运、无魔法学徒。
- 手机背景页与人物卡无页面横向溢出，浏览器无 error/warn 日志。
- 仅检查人物卡网页渲染；未生成、下载或打开 PDF 文件。

## 范围

仍仅支持三级矮人与五个子职，背景覆盖为 4 / 16。此版本完成背景与职业解耦，未宣称已经实现完整三宝书选项。后续范围以 [产品定位](product-scope.md) 为准。
