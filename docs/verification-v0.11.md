# v0.11 新人创建引导验证

日期：2026-09-29。

## 变更范围

玩法偏好与复杂度驱动职业推荐。种族、背景、属性、职业配置与法术提供统一推荐入口、理由和替换范围；推荐只在点击后应用。当前步骤显示必填缺项；检查页区分必须完成与可选建议，并提供目标页面跳转与返回清单。

当前职业覆盖仍为六职业、九条三级子职路线。本轮不扩展规则目录或在线冒险管理。

## 自动验证

- `npm run test:rules`：27742 项通过，包含原有规则和输出检查。
- 九路线 × 十种族 × 十六背景：应用职业配置与法术推荐后仍可合法生成，保留原身份、起源、属性和子职，不修改源对象。
- 验证潜行、近战、魔法、支援、自然偏好与复杂度的推荐排序；偏好跨职业沿用，原职业自定义法术仍可恢复。
- 推荐技能会避开起源已有熟练，专精只从熟练技能选择；游侠与游荡者语言避开已掌握语言。
- 德鲁伊卫士只推荐两道可选戏法，说明与推荐一致；配置推荐不覆盖法师的自定义法术。
- 缺项按目标步骤阻断；合法但不推荐的背景与优化建议不阻止生成。
- TypeScript 检查和生产构建通过。主包约 515 KB，仍有超过 500 KB 的非阻断提醒。

## 交互验证

- 在独立本地端口从首次访问开始：选择潜行与解谜后推荐游荡者，沿推荐半身人／罪犯／属性／职业配置完成盗贼并生成上手卡。刷新后角色恢复。
- 删除一项职业技能时，本页显示缺项、下一步禁用。进入检查清单后可跳回职业配置，采用推荐补齐，再继续身份填写。
- 检查页将姓名、阵营和职业技能缺项列为必须完成；补齐后，即使仍有重复工具熟练的可选建议，创建角色按钮也可用。
- 改为魔法偏好和较高复杂度后优先推荐法师。沿法师配置进入法术页，取消蛛网术使准备数变为 5/6，下一步禁用；采用推荐后恢复，完成法师车卡。
- 手机 390 × 844：职业推荐、本步推荐和法术缺项页面无横向溢出；新增清单按钮后增加底部留白，缺项说明完整显示在固定底栏上方。
- 开发期间修改共享状态模块曾触发热更新上下文错误；独立生产预览重新走完战士创建与刷新流程，控制台无错误。
