# v0.2.0 战士人物卡与导出验收

日期：2026-09-28。基于本地接手版本 `cd264db`。范围保持为 3 级战士／勇士／矮人／士兵；未接入新的职业或通用效果引擎。

## 完成内容

- 草稿先检查结构和受支持的方案，再恢复；损坏或新版本草稿在首次覆盖前备份到 `dnd5r-builder-draft-v1-recovery`，备份失败则保留原数据。存储访问/容量异常有页面提示。旧 v1 草稿兼容，未完成角色不能直接恢复到人物卡。
- 姓名、阵营、年龄、文本长度、工具选择与规则选择校验；检查结果可以跳回对应步骤。属性支持 +2/+1 或力量／敏捷／体质各 +1，并可恢复推荐属性。
- 士兵游戏套装选择落实到装备与熟练；矛、短弓加入攻击和精通选项。补齐战士包 A 的 4 GP，与士兵的 14 GP 合并为 18 GP。
- 负调整值正常显示；链甲隐匿劣势、力量不足时的速度与重型武器劣势、精通是否解锁均明确显示。
- 速查 1 页，完整卡 3 页，覆盖全部技能、豁免、语言、感官、抗性、资源、职业／种族／专长、装备与身份。
- 当前 HP、临时 HP、剩余生命骰、回气／动作如潮／石中精妙次数持久化。短休仅回气 +1、动作如潮恢复；长休 HP／生命骰／能力全恢复并清除临时 HP。治疗掷骰由玩家手动记入。
- PDF 和 PNG 按需加载导出库，固定 794px 宽、2 倍像素密度；多页 PNG 合成一张图，PDF 为 A4 分页。先生成，再点击保存链接，避免把生成误报为下载成功。导出期间禁用构筑与资源修改。

## 边界与后续

- 仍是固定战士切片，玩法偏好不会切换构筑；不支持购物、升级、负重、消耗品自动扣除或其他职业。下一阶段可接入法师／塑能师并验证施法模型。
- 直接导出的 PDF 使用高清图片保证中文一致，文字不可搜索；浏览器打印保留文本。视口模拟不等于手机真机，Safari／Firefox 尚未验收。
- 内置浏览器的生成链接数据已取出并校验，但其下载／打印宿主行为没有可靠落盘信号；实际保存与打印兼容性在 Chrome 完成验证。
- 损坏草稿、存储失败的处理已有实现；解析边界经过脚本验证，没有向用户浏览器注入损坏数据或模拟配额失败。
- 54 条断言不是穷尽 D&D 规则的审计，也不是覆盖率百分比。新增规则依据见 `rules-sources.md`。
