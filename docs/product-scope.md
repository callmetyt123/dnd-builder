# 产品定位与交付边界

确认日期：2026-09-29。依据用户本会话纠偏及 Chat 模式「DND5R builder」原始需求。

## 要完成的事情

帮助第一次接触 D&D / TRPG 的玩家完成一个合法、可理解、可带走游玩的 **5R 三级角色**。默认有推荐，玩家能看到推荐理由，也能按故事偏好修改合法选项。主要交付物是新手速查卡、完整人物卡，以及需要的法术／魔宠／伙伴／荒野变形附页，供纸质或电子方式离线使用。

玩家人数不影响产品范围。角色库、多个角色共存、组队管理、遭遇模拟和在线跑团不是本期验收重点；已有资源记录保留维护，不继续作为主线扩张。

## 规则与体验目标

- 规则范围：PHB 2024、DMG 2024、MM 2025 中与三级开卡相关的内容；不混入 2014、UA 或第三方内容。
- 目标覆盖：12 职业、48 子职、10 种族及其谱系、16 背景。五个已实现的职业路线是开发切片，不是最终产品边界。
- 每个职业提供一个适合新人的推荐子职；其他合法子职保留自由选择，并说明复杂度。
- 推荐优先展示；自定义细节可展开。规则合法性、完成度、实现范围、优化建议分开表达；不够优化的合法角色仍可生成。
- 标准数组与背景加值；官方起始装备包及包内选项。不做点购属性、兼职、升级或自由金币购物。
- 姓名由玩家输入，不随机生成或提供示例姓名。保留九宫格阵营的一句话解释、种族寿命参考。
- 正式中文术语遵循 DND5eChm/5echm_web；推荐理由与新手说明由项目自行编写。
- 需主持人批准的选项明确标注，不自动当作通用默认规则。

## 当前交付与未完成项

v0.7 支持五个职业各一个子职、矮人、四种背景；背景已解除与职业的固定配对，共 20 种组合。属性提升、熟练、装备、专长、资源及人物卡均按实际背景派生。法术、祈唤、装备和兽形仍是已标注的精选子集。

后续继续补齐种族／谱系、剩余背景及起源专长、其余职业和子职及三级合法选项。优先验收“新人能选、能理解、能完成并带走人物卡”，不以新增冒险操作按钮衡量进度。

## 验证约定

检查规则计算、来源隔离、旧草稿恢复、桌面／手机车卡流程及人物卡预览。按用户明确偏好，实际下载的 PDF 文件由用户手动查看；自动化不生成、下载或打开 PDF 文件。
