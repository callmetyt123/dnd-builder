# D&D 5R 角色创建器

面向第一次接触 D&D / TRPG 的玩家设计的引导式 5R 三级角色创建器。

## 产品目标

- 新手不理解规则也能沿推荐路径完成合法角色。
- 熟悉规则的玩家可以展开并修改属性、职业选项、武器精通等配置。
- 规则内容限定为 5R 三宝书范围；当前开发切片先实现《玩家手册 2024》的角色创建规则。
- 中文 D&D 术语以 `DND5eChm/5echm_web` 当前发布内容为显示基准；内部规则 ID 始终使用稳定英文 ID。
- 最终目标输出新手速查卡、完整人物卡、PDF 与 PNG。

## 当前里程碑

`0.15.0`：十二个职业均可创建三级角色，已开放 12 职业 / 48 子职路线。

- 本版补齐野蛮人、吟游诗人、牧师、武僧、圣武士、术士的其余 18 个子职。
- 圣武士开放 10 种战斗风格及受祝福的勇士；子职自动法术与手选名额分开。
- 子职切换保留仍合法的配置；新增能力接入新人上手卡、完整卡和独立附页。

以下为已完成的职业与创建能力，按加入版本分组：

**v0.14 · 六条职业入门路线**

- 新增野蛮人／狂战士道途、吟游诗人／逸闻学院、牧师／生命领域、武僧／散打武者、圣武士／奉献之誓、术士／龙族术法。
- 新增职业法术目录：吟游诗人 61 道、牧师 41 道、圣武士 16 道、术士 72 道；自动授予与起源来源单独计数。
- 职业技能与专精、乐器／工具、圣职、10 种超魔选 2、武器精通和圣武士风格方案，接入推荐、校验、草稿、上手卡与完整卡。
- 六条新路线均有三项入门操作；狂暴、功力、激励、引导神力、圣疗、术法点按实际职业独立记录。临时条件不计入常驻数值。

**v0.13 · 德鲁伊、魔契师与游侠扩线**

- 新增大地、海洋、星辰结社；至高妖精、天界、旧日支配者宗主；猎人、幽域追猎者、妖精漫游者，共九条路线。
- 补齐三级可选职业法术目录：德鲁伊 54 道、魔契师 39 道、游侠 14 道；自动授予与手选名额分开，祈唤开放 10 项。
- 地形、星座、宗主能力与游侠子职选择接入推荐、校验、草稿、新人上手卡和完整卡；准备野兽召唤术时附独立灵魄数据页。

**v0.12 · 战士与法师扩线**

- 新增战斗大师、奥法骑士、灵能武士、防护师、预言师、幻术师；均接入推荐、校验、上手卡与完整卡。
- 战斗大师开放 20 项战技；法师戏法／一环／二环共 90 道，按学习来源和学派分别校验。奥法骑士沿用法师目录的戏法与一环部分。
- 额外技能与工具、战争联结、灵能骰、守御 HP、预兆记录及幻术强化均随实际子职生成。

**v0.10 至 v0.11 · 新人创建与车卡交付**

- 玩法偏好与复杂度产生两条职业建议，显示理由和需要管理的内容；选择不会被自动替换。
- 种族、背景、属性、职业配置与法术提供统一推荐入口，按钮旁说明修改范围。
- 当前步骤有必填缺项时直接提示并阻止继续；检查页分开列出必填项和可选建议，支持跳转修改与返回清单。
- 完成页聚焦检查、修改与带走角色，移除 HP 加减、休息、施法扣位、变形和伙伴等在线冒险操作。
- **新人上手卡**固定一页：角色定位、回合入门、三个常用选择、三项实际熟练技能及两条提醒。不附法术清单或其他数据页。
- 上手建议来自实际所选武器、法术、祈唤、技能、兽形与子职；有合法自定义时，不用默认推荐覆盖它。
- **完整人物卡**保留完整数值、能力、装备和身份；按实际构筑附上起源、法术、兽形、魔宠或伙伴页。
- 完整卡提供当前 HP、临时 HP 的手写位置，以及资源、法术位和生命骰的已用勾选框。旧冒险状态保留在草稿中，但不影响新生成的卡片。
- 两种卡分别支持 PDF、PNG 和打印，手机预览自适应，导出树保持独立 A4 宽度。

已开放：战士／勇士、战斗大师、奥法骑士、灵能武士；法师／塑能师、防护师、预言师、幻术师；游荡者／盗贼、刺客、诡术师、魂刃；德鲁伊／月亮、大地、海洋、星辰结社；魔契师／邪魔、至高妖精、天界、旧日支配者宗主；游侠／驯兽师、猎人、幽域追猎者、妖精漫游者；其余六职业的四个子职见 v0.15 分组。全部 10 种族与谱系、16 背景、10 起源专长、标准数组和包 A 继续支持。祈唤、兽形和职业装备仍有已标注的精选范围。

**v0.15 · 全部 48 个子职**

- 十二职业均可创建三级角色，12 职业 / 48 子职路线已开放；这是对 v0.14 六条入门路线范围的扩展。
- 三级可选内容仍按已标注的支持范围逐步补齐。见 [产品定位](docs/product-scope.md)。

v0.15 详情：十二职业现有全部 48 个 PHB 2024 三级子职入口。新增六职业的其余 18 个子职，包含独立能力、自动法术、资源恢复、推荐说明与纸卡子职页；圣武士可选十种战斗风格或受祝福的勇士。切换子职保留身份、起源、属性和合法选择，仅移除超额或冲突项；配置和法术页提示缺额，可手选或主动采用推荐。兽心示例与时械外观可保存，旧 v0.14 草稿缺少这两个可选字段时仍可恢复。新人上手卡保持一页、三个操作；兽心与武僧子职施法独立附页，不授予职业法术位。狂野术法包含 d100 浪涌速查及随机法术简写，随机生物由主持人查 MM 数据卡。起始装备仍使用包 A，没有金币购物或穿戴编辑器；舞蹈学院按携带但不穿皮甲计算。48 子职并不代表三宝书所有车卡选项都已覆盖；早期职业仍有页面已标注的祈唤、风格与装备等范围限制。

## 开发

```bash
npm ci
npm run dev
```

规则引擎自检：

```bash
npm run test:rules
```

依赖已通过 npm 官方源安装并生成 `package-lock.json`。Vite 7 要求 Node `^20.19.0 || >=22.12.0`。

## 目录

```text
src/
├── app/              # 应用入口
├── pages/            # Builder 各步骤
├── components/       # 通用 UI / Builder UI
├── data/             # 规则数据
├── rules/            # Effect/派生/校验引擎
├── store/            # Builder 状态和 localStorage
├── utils/            # 按需加载的导出逻辑
└── translations/     # 5echm_web 对照显示层
```
